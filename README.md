# Faisal Ahmed Khan — Academic Portfolio

## Run locally

Open PowerShell in this folder, then run:

```powershell
& 'C:\temp\node\node-v20.15.0-win-x64\npm.cmd' run dev
```

Open the URL Astro prints (normally `http://localhost:4321/`). Build the production site with `npm.cmd run build`.

## Add content

- **Article:** create a Markdown file in `src/content/articles/` with a title, date, summary, and body. The folder is ready for your content.
- **Project:** add the project’s problem, motivation, objectives, method, tools, status, limitations, and next steps to the Projects page. Avoid claiming outcomes you cannot verify.
- **Lesson:** add its subject, short description, notes, and only a genuine YouTube URL to the Learning & Teaching page.
- **Resource file:** place the real file in `public/resources/`, then link it from Resources with its format and description.
- **Contact:** replace the Contact page’s placeholder with your intended public email and professional links.
- **CV:** replace the editable text on the CV page. Use the built-in print button to save a PDF; add a download only after making the PDF.

The current pages deliberately use clear empty states rather than invented entries. This keeps the portfolio accurate as it grows.
